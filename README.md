Práctica 7 - Docker Compose con MySQL

Descripción

En esta práctica desarrollé una aplicación web sencilla de Hola Mundo, utilizando PHP como lenguaje de programación y MySQL como sistema de gestión de bases de datos.

Para ejecutar la aplicación utilicé Docker Compose, que permite configurar y ejecutar los diferentes servicios del proyecto mediante contenedores, sin necesidad de 
instalar MySQL directamente en la computadora.

Tecnologías utilizadas

PHP 8.2: lenguaje utilizado para desarrollar la aplicación.

Apache: servidor web encargado de ejecutar PHP.

MySQL 8.0: base de datos utilizada para almacenar la información.

Docker: herramienta para ejecutar los servicios mediante contenedores.

Docker Compose: permite configurar y ejecutar los servicios de la aplicación.
